Install from source
# Get KCoral
git clone https://github.com/mlc-ai/kcoral.git
cd kcoral

# Set up the client
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
↳ Your client runs without a local GPU.

Building from source requires Python 3.10+, Rust 1.87+, and a C/C++ toolchain. See the installation guide for server dependencies.
